隱私權政策

最後更新：2026 年 9 月 21 日

YT Music Publisher（以下稱「本網站」）是用來把音樂與封面製作成影片、發布到 YouTube 並備份到 Google 雲端硬碟的工具。 本網站只開放給事先授權的帳號使用。

一、我們存取的資料與用途

  • 電子郵件地址：確認登入者及使用權限。
  • Google 雲端硬碟：存放你上傳的音樂與封面。
  • YouTube：上傳本網站製作的影片至你授權的頻道。

本網站不會修改或刪除你雲端硬碟與 YouTube 頻道上既有的任何內容。

二、你提供的檔案

你上傳的音樂與圖片只用於製作影片與備份，處理完成後即從我們的系統刪除。 製作好的影片存放在你授權的 YouTube 頻道，音樂與封面存放在你自己的 Google 雲端硬碟。

三、資料保存

我們只在提供服務所需的期間內暫時保存資料，不建立使用者檔案，也不做任何追蹤或廣告分析。 登入狀態會在一段時間後自動失效。

四、資料分享

我們不會出售、出租或提供你的資料給任何人。 為了提供服務，資料只會經過必要的雲端服務供應商處理，並受其安全與隱私規範保護。

五、Google API 服務使用者資料政策

本網站使用與傳輸從 Google API 取得的資訊時，會遵守 Google API 服務使用者資料政策， 包括其中的「有限使用」（Limited Use）規定。從 Google API 取得的資料只用於上述功能， 不會用於廣告，也不會轉讓給他人。

六、Cookie

本網站只使用維持登入與安全所需的 Cookie，不使用追蹤或廣告 Cookie。

七、撤銷授權與刪除資料

  • 隨時可以到 Google 帳戶的第三方存取權 移除本網站的存取權。
  • 雲端硬碟上的檔案與 YouTube 上的影片屬於你的帳戶，可以自行刪除。

八、政策變更

本政策如有修改，會更新本頁並調整上方的「最後更新」日期。

九、聯絡我們

對本政策或你的資料有任何問題，請透過 Google 授權畫面上顯示的「開發人員聯絡資訊」與我們聯絡。
